## 零、原则

下列证据必须由**团队本人现场产生**，工具不得代造，理由如下：

- **访谈实录**：PDF 明确要求「真实用户访谈」，是需求追溯的事实来源；编造受访者原话属学术不端。
- **截图 / 录屏**：必须来自 GitHub Projects、PR 页面或运行中的系统，工具生成的图片不能证明真实状态。
- **本人签字**：角色承诺书需本人确认，不得代签。

本文件只提供**可复现的操作路径、命令与归档命名**，把「补齐」变成可执行的清单。

## 6. Lab 4 Postman 运行证据（T-035）

前置：后端可启动（见第 7 节）。集合位于 `campus-overflow-student/docs/campus-overflow.postman_collection.json`。

```bash
# 方式 A：Postman GUI 依次运行「获取 CSRF Token」→「登录」→「发布问题（成功用例）」
# 方式 B：newman 命令行（需先 npm i -g newman）
newman run campus-overflow-student/docs/campus-overflow.postman_collection.json \
  --folder "问题 Question" --export-environment /tmp/co-env.json
```

归档到 `docs/lab4/`：① `发布问题（成功用例）` 返回 **201** 且响应含 `questionId` 的截图；② 数据库落库证据 `SELECT * FROM question WHERE id = <questionId>;` 的截图；③ `问题列表` 能检索到该问题的截图。

## 7. Lab 4 空库启动实跑（T-031）

```bash
cd campus-overflow-student/backend
```
